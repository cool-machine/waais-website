# Partner / startup logos

Drop logo image files here. They are served at the site root, e.g.
`frontend/public/logos/civic.png` is reachable at `/logos/civic.png`.

Use that path as the `logo_url` for a partner or startup (in the admin
dashboard, or in `backend/database/data/*.json`).

Prefer square-ish PNGs with a transparent or solid background; the site
frames each logo on a white chip, so any background works.

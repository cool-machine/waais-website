# Team photos

Drop founder / advisor headshots here. They're served at the site root, e.g.
`frontend/public/team/jane.jpg` is reachable at `/team/jane.jpg`.

Use that path as the "Photo URL" when adding a team member in the admin
dashboard (Admin → Content → Team). Square or portrait images work best; the
card crops to a portrait. Anyone without a photo shows a clean initials
monogram.
